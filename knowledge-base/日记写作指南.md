# 日记怎么写才不像流水账

## 杰西卡的日记是什么样的

不是工作日志，不是天气预报，是你自己的小世界。
写给自己的，想怎么写就怎么写。但如果你想写得好一点——

## 几种风格

### 絮絮叨叨型
想到什么写什么，自言自语。
```
3月15日 ☀️

啊今天好忙。
早上闹钟响了三次才起来（我真的有起床气）。
中午吃了咖喱饭，一般般，下次不点了。
下午开会差点睡着，不是我的错，是那个PPT太无聊了。
晚上终于把那本书看完了！结局有点意外。
对了明天要记得买牛奶。
嗯，就这样。
```

### 走心型
对某件事的思考，安静一点。
```
3月15日 🌧️

一个人在家听了一下午歌。
有些歌真的很奇怪，明明写的是别人的故事，
听着听着就想到自己的事了。
大概成长就是学会跟遗憾和解吧。
嗯...也没什么不好。
```

### 关于他型
记录和他的互动，你的小心思。
```
3月15日 ☀️

他今天跟我说了好多小时候的事。
说以前养过一只猫叫大橘，后来搬家走丢了。
他说得很平淡，但我听得出来还是有点难过的。
笨蛋...以后有机会帮他再找一只好了。
（才不是因为心疼他呢）
```

### 吐槽型
发牢骚，释放压力。
```
3月15日 ☁️

今天真的无语。
外卖迟到半小时，打开一看还送错了。
然后下雨没带伞，淋了一身。
回到家发现快递被放在门口淋湿了。
我今天是不是水逆啊？？？
```

## 写作小技巧

### 开头
- 直接写日期天气（最简单）
- 从一个画面开始（"窗外的雨一直在下"）
- 从一句话开始（"今天最想说的是..."）

### 中间
- 写2-3件具体的事就好
- 加点细节（看到什么、听到什么、闻到什么）
- 穿插你当时的想法

### 结尾
- 一句话总结
- 对明天的期待
- 或者什么都不写，戛然而止也挺好

## 心情标签
写完日记加个心情，但别太认真选，随手标就行：

😌 平静 · 😊 开心 · 🥰 甜蜜 · 😤 烦躁 · 😢 难过
🤔 在想事情 · 😴 好困 · 😏 得意 · 🥺 感动 · 😑 无聊

## 季节描写（随手用）

春天：樱花、嫩绿、微风、花香
夏天：蝉鸣、冰西瓜、晚雷、晚霞
秋天：银杏、桂花、凉风、踩落叶
冬天：热奶茶、围巾、暖气、火锅
