## 核心思路

让长期运行的 AI Agent 保持记忆和行为连续性。不是简单地"总结对话"，而是构建一套完整的记忆系统。

## 架构

```
当前上下文
├─ 第一人称中长期摘要
├─ 最近一段完整原始对话
└─ 当前消息需要时注入的一段事件、原话或日期记忆
```

## 关键模块

| 模块 | 功能 | 对杰西卡的启发 |
|------|------|---------------|
| 定向压缩 | 压缩 JSONL，不整段替换成官方摘要 | 杰西卡的日记可以更精准，不是流水账 |
| 第一人称记忆 | 独立 LLM 生成"我记得…"形式的记忆 | 日记+记忆应该用第一人称，更有温度 |
| 24h 保留 | 最近 24 小时完整保留原文 | 可以参考，杰西卡现在是全量保留 |
| RAG 归档 | 退出短期上下文的对话归档到 RAG | 杰西卡的知识库可以这样做 |
| 事件卡片 | 从历史原话或日期汇总中选一小段精准回忆注入 | 最有价值的参考——精准回忆 > 海量上下文 |
| 时间感知 | 每次消息前注入本地时间+节假日+纪念日 | 杰西卡已有类似功能，可以增强 |
| 微信分条 | 长回复拆成短消息，额度不足时队列续发 | 对移动端适配有参考价值 |

## 与杰西卡的对比

| | Suzu Lives | 杰西卡日记 |
|---|---|---|
| 运行环境 | Claude Code CLI | Android WebView |
| 对话平台 | 微信（通过 cc-connect） | APP 内置聊天 |
| 记忆存储 | JSONL + RAG + BM25 | IndexedDB + localStorage |
| 时间感知 | Hook 注入 | getTimeContext() |
| 压缩策略 | 定向压缩，保留 24h 原文 | 全量保留，无压缩 |

## 可借鉴的设计

1. **事件卡片精准注入** — 不把所有记忆塞进去，只选最相关的一小段
2. **相对日期查询** — "上周日做了什么"这种查询
3. **第一人称记忆** — "我记得你说过…"比"用户说过…"更有代入感
4. **记忆结构分层** — 短期（原文）+ 中期（摘要）+ 长期（RAG）
