## 项目简介

Next.js 构建的高颜值毛玻璃（Glassmorphism）风格个人博客。自带完善的前端展示与独立的本地后台控制台，支持 Markdown 沉浸式写作、草稿管理以及图床配置。支持移动端适配。

## 技术栈

- **前端**：Next.js
- **后台**：本地控制台（独立运行）
- **图床**：可配置
- **部署**：推荐 Vercel

## 亮点

- 🪟 毛玻璃设计风格
- 📝 Markdown 沉浸式写作
- 📋 草稿管理
- 🖼️ 图床配置
- 📱 移动端适配
- 🔄 自带无损更新器
- 🎮 类创意工坊功能、等级系统

## 对杰西卡的参考价值

- 毛玻璃 UI 风格 → 杰西卡首页可以借鉴
- 本地后台 → 杰西卡设置页的管理思路
- 图床集成 → 如果要做音乐/图片托管，这个思路可以参考
