## 技术笔记

- Android WebView 中 `prompt()` 不工作，需用自定义 modal
- `#homepageBg` 必须在 `#homepage` 外部，否则首页隐藏时背景消失
- Python 的 `compile()` 不能检查 JavaScript 语法
- wttr.in API 加 `&lang=zh` 参数请求中文结果
- 正则字符类中 `-` 必须转义或放在末尾
