## 一、今日完成的工作

### 1. 日期感知修复

**问题**：杰西卡无法区分"昨天"和"今天"，回复中经常出现时间错乱。

**分析**：
- API 日期注入已存在（line 12716-12719）：`[${dateStr} ${timeStr}]` 前缀
- 侧边栏日记列表有 `.diary-date-group` 日期分组
- 主聊天区 `renderAllMessages()` 和 `renderMessage()` 均无跨天检测

**修复**：
1. **CSS 样式**（line ~209）：新增 `.date-separator` 居中灰色分隔条
2. **`isSameDay(ts1, ts2)` 函数**：通过 `getFullYear/Month/Date` 三值相等判断同一天
3. **`createDateSeparator(ts)` 函数**：生成"——— {月}月{日}日 · {今天/昨天/具体日期} ———"格式分隔块
4. **`renderAllMessages()` 补丁**：虚拟滚动渲染循环中首次或跨天时插入日期分隔块
5. **`renderMessage()` 补丁**：单条追加时也检测跨天，插入分隔块
6. **`buildSystemPrompt()` 补丁**：在系统提示词中插入日期感知指令，告诉杰西卡用 `[MM/DD HH:mm]` 前缀判断时间关系

**代码位置**：jessica_full.html，约 22485 行

### 2. PDF / txt 解析改进

**问题**：上传扫描版 PDF 时统一弹出 alert 阻断体验；网络失败和内容为空混为一谈。

**修复**：
1. **`parsePDF()` 区分逻辑**：
   - 正常返回：纯文本 string
   - 扫描版/无文字 PDF：返回 `{empty: true}` 对象（不 throw）
   - 网络错误：throw error
2. **`addDocument()` 错误分类**：
   - 扫描版 PDF → `showToast('这是扫描版PDF，无法提取文字内容', 'warn')`（不阻断）
   - 网络错误 → `showToast('PDF解析失败，请检查网络连接')`
   - 内容过少 → `showToast('文档内容过少，仅N字')`

## 三、技术笔记

- **`isSameDay(ts1, ts2)`** 通过 `getFullYear/Month/Date` 三值相等判断同一天，避免时区干扰
- **`parsePDF` 返回值类型**：string（正常/空内容）或 `{empty:true}`（扫描版）或 throw error（网络失败）
- **游戏删除经验**：小游戏代码分散在 CSS/HTML/JS 三处，需全部清理才能真正减少体积
- **足球代码清理**：关键词搜索要包含变量名（PL/football/Football），避免遗漏
- **`.hp-grid` safe-area**：首页网格区域需要和 `.hp-header` 一样加顶部 safe-area padding，否则内容被导航栏遮挡
