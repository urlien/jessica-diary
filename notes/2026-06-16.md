## 白天 — v3.3.1 功能开发

### 热更新系统

新增 APP 内热更新。APK 装一次就够，后续更新走网页。

设置页新增「应用更新」面板：版本名称 + 检查按钮 + 下载进度条 + 立即更新。每 6 小时静默检查一次，有新版弹 toast。

版本号带代号，比如 v3.3.1「夏至」。以后每个版本都起个名字，用节气/时令/心情都行。

### 记忆全量备份

云备份（GitHub Gist）之前只收集 localStorage，漏了 IndexedDB 的记忆数据（`_idb_memories`）。现在补上了。

恢复时同步还原记忆，不丢数据。JSON 去掉格式化空格，体积减少约 25%。

### 日历标记修复

`getEntryDates()` 之前只检查 messages 数组，导入记忆后前几天的日历没有标记。现在同时检查 messages + jp_entries + memories。

### 登录界面移除

删除启动时的登录/注册流程，打开 APP 直接进主页。

**踩坑**：`LoginUI.init()` 直接调用 `window.initApp()`，但这个函数在文件末尾才定义。DOMContentLoaded 时执行 init()，initApp 还是 undefined，应用永远不启动。用 setTimeout 轮询修复。这个问题之前就出过一次。

## 下午 — 像素城市背景（已放弃）

### 奇思妙想

想把首页的动态像素城市背景从"小学生水平"提升到"大学生水平"。参考了 Waneella 的像素画风格和 Steam 上的 Wallpaper Engine 壁纸（赛博朋克城市）。

尝试了以下方向：

1. **剖面视角**（像小人国/娃娃屋，能看到房间内部）—— 用户说"不要剖面，要外立面"
2. **外立面 + 3D 等距** —— 画了 v5-v7，建筑太黑、霓虹光晕太突兀
3. **参考赛博朋克2077截图** —— 用像素风复刻 CP2077 的城市截图，效果不对
4. **直接用真实截图 + CSS 滤镜** —— 生成了 6 种状态的预览（深夜/黄昏/白天/雨夜/雾天/霓虹夜）

### 最终结论

用真实截图做背景 + CSS 滤镜模拟时间天气的方案可行，但需要高质量的城市截图素材。暂时放弃，保持原来的像素风渲染。

以后会再试一次。下次的思路：
- 准备 2-3 张不同角度的高质量城市截图
- 用 CSS 滤镜 + Canvas 叠加实现时间/天气变化
- 或者请美术同学画一张像素风的城市底图

## 晚上 — v3.3.2 修复

### 英超卡片移除

删除首页英超积分榜卡片及所有相关代码（CSS、HTML、PL 对象、PL 函数、PL 覆盖层）。保留聊天中的足球数据查询功能（支持多联赛）。

### 聊天界面透明背景

聊天区域背景改为半透明（rgba 85% 不透明度），添加 backdrop-filter 模糊效果（8px）。可以隐约看到首页背景，增加层次感。

### 登录跳过修复（关键）

**问题**：v3.3.1 的登录跳过代码直接调用 `window.initApp()`，但该函数在文件末尾才定义，导致应用卡在启动页。

**修复**：用 setTimeout 轮询等待 initApp 定义完成后再调用。

**状态**：已修复但用户反馈仍然卡死，待进一步调试。

### 热更新修复

移除启动时自动应用缓存逻辑（旧缓存可能导致卡住），改为手动检查更新（设置页面）。
