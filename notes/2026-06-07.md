# 2026-06-07 工作记录

## 移动端全屏适配

针对 Redmi K60 做的专项适配。

### 问题

- 100vh 在 Android WebView 中不稳定，可能包含状态栏/导航栏区域
- 弹性滚动、下拉刷新干扰体验
- 滚动穿透到父元素

### 解决

- `100vh` → `100%` + `position: fixed; inset: 0`
- `overscroll-bezier: none` 防弹性滚动
- `overscroll-bezier: contain` 防滚动穿透
- WebView 禁用缩放，HTML 完全控制布局
- 全屏沉浸模式，内容延伸到状态栏和导航栏后面

### Android 端

- `setLoadWithOverviewMode(true)` — 概览模式加载
- `setUseWideViewPort(true)` — 宽视口
- 禁用缩放控件

### 吐槽

Android WebView 的 100vh 是个经典坑。浏览器里 100vh 就是视口高度，但 WebView 里可能把状态栏、导航栏的高度也算进去。解决方案就是不用 vh，用 % + fixed。这种平台差异性，文档里不会告诉你，只有踩过才知道。

## v3.1.0

### 新增

- **版本号系统**：APP_VERSION 显示在设置页底部
- **压缩包导出**：JSZip 生成 .zip，移动端走 Web Share API
- **表情包批量上传**：多选图片，一次添加多张
- **首页日记编辑+重新生成**：日记卡片底部加了编辑和重新生成按钮
- **动态人设**：设置页显示杰西卡和用户的学业状态，随时间自动切换
- **地图系统重做**：Leaflet 地图，中心固定图钉，拖动选位置

### 修复

- 移动端数据导出：改用 Web Share API
- 知识库上传：移动端 label for 不靠谱，改用 onclick
- 通知开关：去掉硬编码 checked，即时保存
- 天气系统：全中文
- 主动消息：不虚构不存在的对话

### 吐槽

v3.1.0 的改动量比 v3.0.0 大得多。版本号、导出、表情包、日记编辑、人设、地图……一天之内塞了这么多功能进去。

最坑的是移动端导出。PC 端直接创建 `<a>` 标签点击下载就行，移动端不行。得用 Web Share API，而且还要处理 fallback。每个平台的"下载文件"这件小事，实现起来都不一样。

还有地图。Leaflet 本身挺好用的，但在 WebView 里嵌地图，触摸事件冲突是家常便饭。拖地图和拖页面打架，得手动处理 `touch-action`。

## 总结
